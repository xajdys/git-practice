# What I learned in this practice:

## Git Glossary:
- Git = the system that records every version of your project
- Commit = a saved checkpoint
- Branch = a separate line of work
- Merge = combining work from two branches
- Pull request = “here’s my work, please review and merge it”

## Habits I learned:
- Check git status before and after work
- Keep commits small and focused
- Write clear commit messages
- Branch for each feature/fix
- Don’t mix unrelated changes in one commit
- Merge only when code is ready
- Resolve conflicts carefully, not blindly
